# Imaging Session

The following is an example workflow for an imaging session:

1. Open a command prompt and enter `activate oas && oas` to run the GUI.
2. Select the directory for the imaging data.
3. If using plane-interpolated Z tracking, enable it in the GUI. Focus at three reference positions on the sample surface and press the corresponding 'Set Point' button at each position.
4. Use the GUI or Xbox controller to bring the animal into the field of view.
5. Select the XY tracking model for the imaging conditions and developmental stage.
6. Confirm that the tracker localizes the terminal bulb correctly in the behavior display.
7. Start XY tracking and, if configured, Z tracking.
8. Start recording the image streams.
